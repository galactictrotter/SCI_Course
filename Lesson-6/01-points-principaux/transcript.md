# Points principaux

1. Parce que la réussite dans l'action dépend directement de la connaissance, celle-ci doit être vraie, englobante, juste, utile - scientifique.

2. L'étude de l'Intelligence Créatrice est scientifique parce que :

   - L'Intelligence Créatrice peut être expliquée logiquement pour satisfaire toute quête intellectuelle.
   - L'Intelligence Créatrice peut être expérimentée directement, dans son état pur.
   - L'Intelligence Créatrice peut être vérifiée objectivement à partir d'expériences reproductibles.
   - L'Intelligence Créatrice peut être exprimée artistiquement dans sa pleine valeur.
   - L'Intelligence Créatrice peut être totalement développée et appliquée par quiconque, dans tous les domaines d'activité.

3. La Science de l'Intelligence Créatrice offre une connaissance et une expérience :

   - profondes
   - complètes
   - utiles
   - sources de plénitude
   - universelles
